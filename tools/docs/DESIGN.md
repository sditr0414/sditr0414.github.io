# 포트폴리오 디자인 기준

## 화면 구성

기계·로봇 분야의 제작물과 구현 과정을 읽는 엔지니어 포트폴리오입니다. 네이비 표지와 흰색 본문, 실제 사진·회로도·실험 화면을 중심으로 구성합니다. 프로필과 학력·교육, 프로젝트 5개를 13장에 담습니다. 팀 전체 기능과 개인 담당 범위를 구분하며, 기술이나 성과를 장식용 수치로 추가하지 않습니다.

- 표지: 이름과 지원 분야, 소개, 프로젝트·실습에서 사용한 기술 순으로 배치합니다.
- 프로젝트 개요: 왼쪽에 제작물 이미지, 오른쪽에 설명·담당 역할·기술·시연 버튼을 배치합니다.
- 상세 페이지: 구성도와 구현·개선·검증 내용을 같은 그리드와 제목 체계로 연결합니다.
- 목차: 화면 오른쪽 가운데에 작은 플로팅 목차를 둡니다. 전체 프로젝트명을 표시하고, 얇은 세로선과 짧은 강조선으로 현재 위치를 구분합니다. 현재 프로젝트의 세부 페이지 번호를 함께 표시합니다.
- 모바일: 이미지를 먼저 보여 주고 본문을 세로로 배치합니다. 목차는 상단 버튼에서 열며 시연 버튼은 본문 너비로 표시합니다.

## 문체

본문은 정중한 서술형으로 쓰고, 제목과 소제목은 구현 내용이 바로 드러나는 간결한 표현을 사용합니다. 개인 기여는 “담당 역할”로 통일합니다. 프로젝트에서 한 일·확인한 결과·남은 한계를 구분하며, 수치·기술 사양·팀원 담당 범위와 AI 도구 활용 사실은 유지합니다.

## 색상과 글자

| 역할 | 색상 |
| --- | --- |
| 표지 · 13페이지 기능 흐름 | `#355674` |
| 주요 버튼 | `#18344d` |
| 표지 사진 뒷면 | `#2b4760` |
| 본문 | `#1e2d3d` |
| 보조 본문 | `#596777` |

| 보조 영역 | `#f3f5f7` |
| 구분선 | `#d9dfe5` |

폰트는 Noto Sans CJK KR을 우선하는 한국어 시스템 폰트 조합입니다. 데스크톱 이름 50px, 페이지 제목 30px, 본문 16px를 사용합니다. 목차는 13px로 표시하며 긴 이름은 줄바꿈합니다. 얇은 구분선과 제한된 색상으로 정보를 구분하고, 원본 사진·화면의 색상은 바꾸지 않습니다.

현재 테마는 `docs/assets/css/styles.css`의 `Engineering portfolio` 구간에서 관리합니다. 인쇄용 복제 페이지에는 ID가 없으므로 표지는 `#profile`이 아니라 `.cover`로 지정합니다.

## 웹과 출력

- 웹과 PDF는 같은 1120×630px, 16:9 `.slide`를 사용합니다.
- PDF에서만 글자를 줄이거나 내용을 숨기지 않습니다.
- 모바일에서는 높이를 자동으로 늘려 내용을 모두 표시합니다.
- 16:9 PDF는 13장, A4 세로 인쇄본은 같은 슬라이드를 두 개씩 배치한 7장입니다.
- 폰트 파일은 배포하지 않습니다.
- 스타일과 스크립트를 변경할 때 `docs/index.html`의 자산 버전 쿼리를 갱신합니다. 단일 HTML 생성기는 이 쿼리를 제외한 경로로 자산을 읽습니다.

## 자료 보기

시연 영상은 재생 아이콘이 있는 네이비 버튼으로 제공합니다. 영상 창은 가용 화면에 맞추고 전체 화면과 기본 재생 컨트롤을 제공합니다. 이미지는 확대 창에서 화면 맞춤·원본 크기를 전환하며, 전공 실습 자료는 갤러리로 탐색합니다. 키보드 포커스, Escape 닫기, 동작 감소 설정을 유지합니다.

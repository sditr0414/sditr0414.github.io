# 포트폴리오 디자인 기준

## 기본 구성

프로필과 학력·교육, 프로젝트 5개를 13장의 슬라이드로 구성합니다. 짙은 네이비 표지와 밝은 본문, 작은 플로팅 목차를 사용합니다. 팀 프로젝트의 기능과 개인의 담당 범위를 구분합니다. 이미지와 시연 영상은 원본 자료를 사용합니다.

## 표지 색상

| 역할 | 색상 |
| --- | --- |
| 웹 바깥 배경 · 기존 유지 | `#e7eef8` |
| 1페이지 바탕 | `#24476b` |
| 우측 사진 영역 | `#1b3552` |
| 사진 프레임 | `#345779` |
| 이름 | `#ffffff` |
| 소개 문장 | `#f0f6ff` |
| 본문 설명 | `#d3dfef` |
| 기술 목록 | `#dce7f6` |
| 보조 정보 | `#bdcfe5` |
| 구분선 | `#526f8f` |

규칙은 `assets/css/styles.css`의 표지 색상 구간의 `.cover`에만 적용한다. 인쇄용 복제 페이지에는 ID가 없으므로 `#profile`이 아니라 `.cover`를 사용한다. 사진과 캡처의 색상은 변경하지 않는다. 그라디언트나 새 장식은 추가하지 않았다.

## 공통 화면과 출력

- 웹과 PDF의 원본은 1120×630px, 16:9의 같은 `.slide`이다.
- 글자 크기, 줄바꿈, 이미지 배치는 변경하지 않는다.
- A4 세로 한 장에 같은 슬라이드 두 개를 비례 축소해 배치한다.
- 모바일의 세로 배치는 유지하며, PDF는 데스크톱 원본을 기준으로 한다.
- 출력은 설치된 Noto Sans CJK KR로 확인했다. 폰트 파일은 배포하지 않는다.

## 시연 영상

시연 영상은 재생 아이콘이 있는 네이비 버튼으로 표시합니다. 모바일에서는 버튼을 가로폭에 맞춥니다. 영상 창은 화면에 맞춰 확대하고, 전체 화면 버튼과 기본 재생 컨트롤을 제공합니다.
